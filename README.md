# Soldaten Multi Tool

Basit ve kullanışlı çok amaçlı Python aracı.

## Özellikler
- Local IP gösterimi
- Rastgele güçlü şifre üretici
- Basit hesap makinesi
- Sistem bilgileri
- IP değiştirme önerileri (VPN)

## Nasıl Kullanılır?
1. Python yüklü olsun
2. `soldaten.py` dosyasını indir
3. Terminalde `python soldaten.py` yaz

Hazır!
