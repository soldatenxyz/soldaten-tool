# SOLDATEN

Terminal tabanlı gizlilik, güvenlik ve ağ aracı.  
**31 özellik** — Windows ve Linux (Kali dahil) üzerinde çalışır.

---

## Hızlı Kurulum

### Kali Linux / Linux

```bash
git clone https://github.com/soldatenxyz/soldaten-tool
cd soldaten-tool
chmod +x setup.sh
./setup.sh
```

Kurulum biter, çalıştırmak için:

```bash
./run.sh
```

### Windows

```
setup.bat
```
